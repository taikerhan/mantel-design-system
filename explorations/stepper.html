Where does the unit go?

Same value, two placements — on a duration example

Option A — Unit as a suffix

.ex-stepper-group + .ex-stepper-unitunit rides outside the control
days
hrs
min
Unit rides outside the control as muted ink-500 text. The stepper stays a pure number control; the row reads left-to-right as "2 days, 3 hrs, 30 min". Matches PatternFly, USWDS, Nord.PatternFly · USWDS · Nord

Option B — Unit as a field label

.mt-labelbest for a standalone form field
Standard form labelling — the unit becomes the field label above. Cleanest when one stepper sits in a vertical form; costs height when three share a row. Matches Carbon, eBay (compact).Carbon · eBay
Do

Keep the stepper a pure number control. Put a fixed unit to the right as a suffix (A); use a field label (B) for a standalone field; use a select (C) only when the unit is choosable.

Don't

Wedge the unit between the value and the + button. It competes with the number and breaks the − / value / + rhythm.
