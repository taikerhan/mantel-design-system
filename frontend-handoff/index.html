Buttons

All rounded-full · ≤1 primary per surface

Primary

.btn .btn-primary40px tall · brand-600 fill
Idle brand-600 · hover brand-700 · text white · 13px / 500height 40 · radius 9999

Secondary

.btn .btn-secondaryThin blue border · default CTA
1px solid brand-600 border · text brand-700 · bg white · hover bg brand-50height 36 · radius 9999

Icon / ghost

.btn .btn-icon36×36 circular · transparent until hover
Idle transparent · hover bg ink-100 · icon ink-500 → ink-90036 × 36 · radius 9999
Do

One primary action per surface. Pair primary + secondary side-by-side; icon buttons trail.

Don't

Stack two primaries. Don't add drop shadows or icons inside the icon-button hover state.

Pill tabs

Soft segmented selector · white track + active filled pill

When to use

Three related selectors — pick by density & intent
Component Best for Notes
Pill tabs
.mt-pill-tabs
 2–5 mutually exclusive view toggles Soft, inline feel. Active is a filled black pill that sits inside the white track. Use inside cards for filtering payment methods, time ranges, or layout views.
Underline tabs
.tabs
 Primary sub-page navigation 4–7 items with count badges. The main navigation inside a workspace (Active / Drafts / Credit hold / Signed / Lost).
Segmented control
.seg
 Hard filter rows in headers Brand-bordered, connected pill. Use in utility / toolbar strips, not as content navigation. ≤4 options.
Pill tabs are the lightest of the three — reach for them first inside a card.decision guide

Default

.mt-pill-tabsCard-shadowed track · inactive items hover to ink-100
Active fills ink-900 with white text · idle ink-700 · hover bg ink-100 / text ink-900.mt-pill-tab.is-active

Tooltips

Dark · hover-triggered · 4 placements
More actions Tooltip below 3 unread brand-600 #0053A7 · primary action
ink-900 bg · 12px medium text · 200ms fade + 4px slide on enter · arrow flips with placement.mt-tip / .is-{top,bottom,right}
Do

Use for icon-only buttons and dense labels that need disambiguation. Keep copy to a short phrase.

Don't

Don't put critical info in a tooltip — they're hover-only on desktop and unreachable on touch. Use a label or inline help instead.
