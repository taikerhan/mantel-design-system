Changelog

Every change to the kit, logged before it's pushed to GitHub. Write the entry as part of the push — bump the version, list what changed, and the top entry becomes the new release.

v2.3.0 Jun 21, 2026 Current release
Added
Loaders page — the former Skeleton page, now a full loader family: spinner (.mt-spinner, sizes + in-button), loading dots (.mt-dots), linear progress (.mt-progress, determinate + .is-indeterminate), and a circular progress ring (.mt-ring) — alongside the existing skeleton & rotating-message loaders, with a when-to-use guide and a Page loaders gallery — top bar (route change), centred spinner, full skeleton & rotating status lines, each shown in a mini app frame.
Added
Toast playground — live props on the Toasts page (tone · title · icon · dismiss · actions), replacing the "Coming soon" placeholder.
Added
Toast — "When to use" guidance: per-tone usage (success / danger / neutral) with a color-token column, plus toast-vs-alert-vs-modal direction.
Changed
Toast — semantic surface: status toasts now take a saturated tone fill across the whole surface — green for success, red for errors (white icon & text) — while neutral toasts keep the dark ink-900 surface. Icons updated to match: success uses a bare checkmark (no ring), errors a warning triangle. The amber warning tone was removed — toasts are success / error / neutral only.
Changed
Checkbox, radio & switch — disabled: disabled controls now use explicit muted fills instead of an opacity: 0.5 wash — checkbox/radio fill the box (--ink-150 unchecked / --ink-300 checked), the switch track pales to --ink-150 (off) / --brand-300 (on) with a softened thumb shadow — so a disabled control reads as inert rather than an empty, clickable field.
Changed
Tabs — mobile scroll: the right-edge fade (.mt-scroll-fade) now clears once the bar is scrolled to the end (toggles .is-end), so it no longer sits over the last tab's label.
Changed
Switch — now defaults to a high-contrast track (ink-400 fill, blue-tinted off border) with an inset "recessed groove" shadow, and gains an off-state hover (track darkens, border deepens). Visibility variants trimmed to High-contrast + Iconized-thumb (Default / Labeled / Iconized-track dropped; playground updated to match).
Changed
Dropdown menu — added a 1px ink-200 border so the menu edge reads against light backgrounds.
Changed
Button elevation — adopted the A · Soft lift candidate for the primary (.btn-default) and destructive (.btn-destructive) buttons: a softer drop shadow with the 3D bevel insets dropped.
v2.2.0 Jun 19, 2026 Superseded
Added
Page header combo (.mt-page-header) — title row + description + actions, with breadcrumb support; lives in a new Combos nav group.
Added
Split button (.mt-btn-split) — a primary action plus a caret that opens a Dropdown menu of rarer variants; now documented under Buttons.
Added
Tabs — small size (.mt-tabbar.is-sm): 38px bar / 14px tabs for card headers & toolbars (size prop 'sm' | 'md'). Mobile bar now scrolls with compact tabs and a right-edge fade (.mt-scroll-fade).
Added
Segmented — stretch (.is-stretch): on phone width, 3–4 options divide the row evenly.
Added
Modal overhaul — size tiers (.is-wide / .is-large / .is-full) on a shared overlay shell (.mt-overlay-head / .mt-overlay-body / .mt-overlay-foot): body-only scroll with pinned header & footer, a backdrop fade + rise-in entrance (was scale-in), plus confirm & static variants.
Added
Right sheet / detail drawer (.mt-sheet-right) — 440px, slides 280ms in / 240ms out, pinned header & footer, scrolling body.
Added
Skeleton loader with rotating status messages (.mt-loader / .mt-loader-msg) for long async loads.
Added
Form input sizes — .is-sm / .is-lg.
Added
Live, interactive Playgrounds on 13 components — Buttons, Form inputs, Tabs, Segmented control, Status pills, Category pills, Strength badges, Alerts, Avatars, Stat card, Live indicator, Switch / checkbox / radio & Breadcrumbs — change variant / size / label / state and see it render, replacing the "Coming soon" placeholder.
Added
Data table row-anatomy reference — .th-row / .row / .cell-{primary,num,center}.
Added
Design review section — a Review queue for explorations awaiting a decision, with status chips (Needs Zac / Exploring / Approved) and a nav count badge.
Added
Button elevation exploration — a dimensionality ruler (Current → Soft lift → Light shadow → Flat) with two live candidates, both keeping a light shadow.
Added
Pending / work-in-progress banner on Design review pages, and a back link from detail pages to the queue.
Added
This Changelog page.
Changed
Renamed the primary button class .btn-primary → .btn-default across the kit.
Changed
Secondary / outline button now uses brand-600 for both text and border (synced to front-end) — a single-blue outline on white, deepening to brand-700 on hover. .btn-outline brought in line with .btn-secondary.
Changed
Breadcrumbs rebuilt on semantic <ol> / <li> markup (.mt-crumb-list) with aria-current="page" and presentational separators.
Changed
Button group refocused to connected peer actions / view switchers (Split button moved out to Buttons), with when-to-use guidance vs. Segmented.
Changed
Search & pickers chrome — from 36px rounded-full / ink-50 fill to 36px 8px-radius matching input + button chrome; focus ring → brand-600.
Changed
Segmented — brand variant: gradient thumb with count-badge inversion at a fixed 40px, plus default-vs-brand usage guidance.
Changed
Stat card — looser vertical rhythm (value 30px / 700, 14px gaps) and delta promoted from a bare line to a tinted pill (.delta-pill); adds inline sparkline & bar variants (.spark / .bar) and a responsive .stat-grid that reflows 4→2→1 instead of crushing on narrow widths.
Changed
Sidebar nav — Overview now reflects its active state on the dashboard, every nav item gained a keyboard :focus-visible ring, and the Review-queue count badge moved onto its nav row.
Changed
Status colour tints deepened one step — accent-green/amber/red-bg plus the Sent & Viewed pill tints — so status pills, strength badges, alerts and the stat delta read at a glance; focus-card surfaces kept soft.
Changed
Body text deepened for stronger contrast — ink-800 #1B1D20 → #15171A.
Changed
Legibility pass (busy 50–60yo vendor audience) — mono-caps eyebrows enlarged to 13px with tighter 0.07em tracking and darkened to ink-600; segmented inactive option + menu section labels / shortcuts darkened; card hairline ring strengthened (5%→9%) so edges read; Typography font toggle rebuilt on the DS .mt-segmented.
Changed
Overview dashboard — content centered + widened to 1280px, a Design tokens · JSON handoff button, and skeleton shimmer on each thumbnail until its lazy iframe loads.
Changed
Typeface — Geist adopted as the sole production typeface; the Typography page's System-sans / Phase-2 preview toggle removed. Segmented track deepened to ink-150 and the disabled-option demo no longer over-stretches.
Fixed
Modal / sheet footer — the primary button now matches the secondary's font-size (was 13px vs 14px side by side).
Changed
Dropdown menu — roomier 40px rows (touch-friendly for mobile viewers), section labels + shortcuts up to 13px, and item text to medium weight so it reads solid at 14px.
Fixed
Page header (and any overlay-free page) no longer logs a console error — the overlay initialiser now guards against a missing backdrop before wiring events.
Removed
Segmented .is-outline legacy variant.
Removed
Standalone Table component — folded into Data table (front-end ships Table row separately; our DS keeps one component).
