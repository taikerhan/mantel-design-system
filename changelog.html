Changelog

Every change to the kit, logged before it's pushed to GitHub. Write the entry as part of the push — bump the version, list what changed, and the top entry becomes the new release.

v2.3.7 Jul 19, 2026 Current release
Review
System details — stacked zones: re-presented full-screen as the real proposal page (team call — regular screen beats demo containers), now built on the Option-details framework: preview ribbon, co-brand app bar, toolbar, price-aware option rail, 720px scroll canvas, and the sticky Review & Sign action bar with one filled primary. The stacked zones and pinned zone navigator become the System details section of a complete proposal — hero title + equipment-photo carousel, Warranty and Benefits above; Recommended upgrades (Add/Added updates the figure) and Select payment method (financing shows /month, credit card the one-time total) below, with section order and copy mirroring the live proposal. The scrollspy rides the proposal's scroll container and the navigator pins inside its own section, released by the section end. The one- / three- / four-system demo toggle moved into the ribbon beside the device preview; the floating bottom pills are gone. Review-queue exploration only, not promoted to the kit.
v2.3.6 Jul 19, 2026 Superseded
Review
System details — stacked zones: follow-up to zones & staging — every system's full equipment and staging chart now stack on one longer card instead of hiding behind tabs, with a small numbered tab row that pins to the top as a scroll navigator (tracks the zone in view, click to jump) once a home has more than one system, and a four-zone phone edge case where the pinned bar scrolls sideways and auto-centers the active tab. Review-queue exploration only, not promoted to the kit.
v2.3.5 Jul 15, 2026 Superseded
Fixed
Multi-select dropdown clipping: the checklist popover was being cut off by the spec card's overflow: hidden (rounded-corner clip). Added an opt-in .spec.is-overflow modifier that lets a card hosting an absolutely-positioned popover overflow, so the menu paints in full over the content below. Site-shell only — the .mt-multiselect component itself was correct.
Fixed
Scrollable tab bar — vertical jitter on swipe: the horizontally-scrolling mobile tab bar (.mt-tabbar.is-scroll) also drifted vertically when swiped diagonally. Locked the cross-axis with overflow-y: hidden + touch-action: pan-x so a swipe only pans horizontally and hands the vertical gesture back to the page.
Added
Scrollable tab bar — edge arrows & left fade: the horizontal tab bar's fade now mirrors on the left edge once scrolled (.is-start), and an optional pair of edge arrows (.mt-scroll-btn.is-prev / .is-next inside .mt-scroll-fade) gives mouse users a click affordance — each pages the bar ±60% of its width and hides at its end of travel. Wired in kit.js off the existing .mt-tabbar.is-scroll hook; honors prefers-reduced-motion. The bar also now composes with the kit's small variant (.is-scroll.is-sm → 38px) — both mobile demos use it.
Review
System details — zones & staging (Option C): added a 4-tab overflow edge case in a 390px phone frame — the numbered zone tabs scroll horizontally (.mt-tabbar.is-scroll) when a home has more zones than the width holds, with a systems count in the header and equipment listed above the chart. Review-queue exploration only, not promoted to the kit.
v2.3.4 Jul 15, 2026 Superseded
Added
Multi-select (.mt-multiselect) — an avatar-token field that opens a searchable checklist popover: selected people stack as overlapping avatars (max 8, then +N) with a live count, and the field's inline input is the filter (no in-menu search box). Checklist rows are the kit checkbox (.mt-check) so Space-toggle and focus come free; keyboard runs ↑ / ↓ / Enter / Esc, and Backspace on an empty input drops the last pick. Wired via [data-mt-multiselect] in kit.js (options seeded from an inline JSON block). Lives on the renamed Search & select page. Promoted from the Review queue — Option 2C.
Changed
Search & pickers → Search & select: the page (and nav / dashboard tile) is renamed to cover all three value-entry modes — search combobox, single-select picker, and the new people multi-select.
v2.3.3 Jul 10, 2026 Superseded
Added
--surface token (#FFFFFF) — a named token for card & control surfaces, so component CSS stops hardcoding #fff. First consumers: the Stepper track and the Stepper page's demo list card; remaining #fff surfaces migrate opportunistically.
Changed
Stepper — bordered track: adopted Option 1 from the Stepper Combo review. The − / value / + trio now rides a white pill track (1px ink-200 inset ring, 5px padding, gap 12→6) so a standalone stepper reads as one control instead of three detached circles — the case the frontend hit in Products to Quote. Value slot 34→40px; .is-sm / .is-lg paddings scale with the track. The Stepper page gains standalone tiles (desktop) and 375px list (mobile) examples.
v2.3.2 Jul 1, 2026 Superseded
Added
Stepper (.mt-stepper) — a control for small bounded quantities: a value flanked by round primary − / + buttons (.mt-stepper-btn, brand gradient + --shadow-button), the spent button fading to 50% at a bound like a disabled .btn. A native <input type=number> holds the value + min/max, wired via [data-stepper] in kit.js. Ships with .is-sm / .is-lg sizes and a .mt-stepper-field list-row layout (label left, control right). Promoted from the Review queue — Option D.
v2.3.1 Jun 22, 2026 Superseded
Added
Switch — large size (.mt-switch.is-lg): a 48×26 track — 52×28 for the iconized variant — with a 24px thumb and a 44px tap target, for mobile-friendly settings toggles. The team's pick is the large iconized switch; the toggles playground now switches size too. The checkbox & radio were bumped a notch — default 18→20px, large (.is-lg) 20→24px — so the large toggle family is uniform at 24px.
v2.3.0 Jun 21, 2026 Superseded
Added
Loaders page — the former Skeleton page, now a full loader family: spinner (.mt-spinner, sizes + in-button), loading dots (.mt-dots), linear progress (.mt-progress, determinate + .is-indeterminate), and a circular progress ring (.mt-ring) — alongside the existing skeleton & rotating-message loaders, with a when-to-use guide and a Page loaders gallery — top bar (route change), centred spinner, full skeleton & rotating status lines, each shown in a mini app frame.
Added
Toast playground — live props on the Toasts page (tone · title · icon · dismiss · actions), replacing the "Coming soon" placeholder.
Added
Toast — "When to use" guidance: per-tone usage (success / danger / neutral) with a color-token column, plus toast-vs-alert-vs-modal direction.
Changed
Toast — semantic surface: status toasts now take a saturated tone fill across the whole surface — green for success, red for errors (white icon & text) — while neutral toasts keep the dark ink-900 surface. Icons updated to match: success uses a bare checkmark (no ring), errors a warning triangle. The amber warning tone was removed — toasts are success / error / neutral only.
Changed
Checkbox, radio & switch — disabled: disabled controls now use explicit muted fills instead of an opacity: 0.5 wash — checkbox/radio fill the box (--ink-150 unchecked / --ink-300 checked), the switch track pales to --ink-150 (off) / --brand-300 (on) with a softened thumb shadow — so a disabled control reads as inert rather than an empty, clickable field.
Changed
Tabs — mobile scroll: the right-edge fade (.mt-scroll-fade) now clears once the bar is scrolled to the end (toggles .is-end), so it no longer sits over the last tab's label.
Changed
Switch — now defaults to a high-contrast track (ink-400 fill, blue-tinted off border) with an inset "recessed groove" shadow, and gains an off-state hover (track darkens, border deepens). Visibility variants trimmed to High-contrast + Iconized-thumb (Default / Labeled / Iconized-track dropped; playground updated to match).
Changed
Dropdown menu — added a 1px ink-200 border so the menu edge reads against light backgrounds.
Changed
Button elevation — adopted the A · Soft lift candidate for the primary (.btn-default) and destructive (.btn-destructive) buttons: a softer drop shadow with the 3D bevel insets dropped.
