Changelog

Every change to the kit, logged before it's pushed to GitHub. Write the entry as part of the push — bump the version, list what changed, and the top entry becomes the new release.

MAJORBreaking — token renames, removed components, anything that needs a migration.
MINORAdditive — new component, new variant or token, backward-compatible.
PATCHFixes — visual corrections, copy, docs, no API change.
v2.2.0 Unreleased Pending push
Added
Design review section — a Review queue for explorations awaiting a decision, with status chips (Needs Zac / Exploring / Approved) and a nav count badge.
Added
Button elevation exploration — a dimensionality ruler (Current → Soft lift → Light shadow → Flat) with two live candidates, both keeping a light shadow.
Added
Pending / work-in-progress banner on Design review pages, and a back link from detail pages to the queue.
Added
This Changelog page.
Changed
Renamed the primary button class .btn-primary → .btn-default across the kit.
Changed
Secondary / outline button now uses brand-600 for both text and border (synced to front-end) — a single-blue outline on white, deepening to brand-700 on hover. .btn-outline brought in line with .btn-secondary.
Changed
Sidebar nav — hairline dividers between sections; search field rest ring darkened to ink-300.
v2.1.0 Jun 14, 2026 Current release
Changed
Buttons moved to 8px rounded corners (from pill); elevation reserved for the primary and destructive focal actions only — secondary / neutral / icon stay flat.
Added
Animated segmented control (.mt-segmented) with a sliding thumb, and category pills (.mt-category) for non-status tags.
Added
CSS-grid data table (.mt-table) with sticky-first-column responsive mode and portalled row-action menu.
Fixed
Tabular-nums applied to every numeric cell, badge, and timestamp for column alignment.
v2.0.0 May 2026 Superseded
Changed
Rebuilt on Geist + the CSS-variable token set (--brand-*, --ink-*, accents); cards standardised on 16px radius and the hairline-ring elevation.
Removed
The legacy component sheet (visible borders + flat grey shadows) — replaced by the tokenised kit.
