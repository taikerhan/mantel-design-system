Tabs

Sliding underline · soft brand active fill · count chips · 280ms spring

Underline

.mt-tabs · .mt-tab · .mt-tab-countSliding 3px brand underline · soft active fill
The underline measures the full tab and sits on the 1px ink-200 rule. Active tab gets a soft brand fill (brand-100 @ 55%); its count chip inverts to brand-600 / white. Switches filtered views of one table.280ms · spring

Underline — multiple views

~5 filtered views of the same table
Keep to ~5 mutually exclusive views, each with a count chip. The indicator re-measures on resize so it stays anchored to the active tab..mt-tab.is-active

Vertical

.mt-tabs.is-verticalSidebar list · left accent bar (CSS-only)
A sidebar list for settings-style navigation. The active item carries a left brand accent bar + brand-50 fill — no sliding underline, so it needs no JS (omit data-mt-tabs and the underline span)..is-vertical

Mobile

.mt-tabbar.is-scrollBar scrolls sideways · vertical collapses to full-width
Swipe the tab bar sideways — the underline keeps tracking the active tab.
At phone width the underline bar scrolls horizontally (overflow-x: auto, scrollbar hidden); the JS keeps the underline measured to the active tab. A vertical Tabs list simply fills the column. Frame is 360px — the smallest target width..is-scroll · 360px

Do

Use underline / pill to switch filtered views of the same table; vertical for settings-style sidebar nav. Add a .mt-tab-count chip so volume reads at a glance.

Don't

Exceed ~5 horizontal views — switch to vertical. On the underline variant, don't drop the .mt-tab-underline span; the JS needs it to carry the sliding edge.
