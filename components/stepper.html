Do

Use for a small, bounded quantity (guests, nights, copies). Set min and max so the spent button disables at the edge, and place it as the right-hand control of a labelled list row.

Don't

Use it for a wide numeric range or free entry (use a number field), and don't bake the unit between the value and +. The unit is the row label on the left.
