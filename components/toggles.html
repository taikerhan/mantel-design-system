Visibility variants

Pick one — try them side-by-side
Variant Off On Notes
Default
.mt-switch
 Where we landed last round. ink-300 track + ink-400 border. Clean, restrained, matches our checkbox/radio family.
High-contrast
.mt-switch.is-strong
 ink-400 track + ink-500 border. ~4.5:1 contrast against white — passes WCAG AA for non-text UI. Best for settings pages where users scan many toggles.
Labeled
.mt-switch.is-labeled
 OFF/ON text in mono inside the track. Wider (52px) — uses real estate but state is unmistakable. iOS uses this on accessibility-larger sizes.
Iconized — track
.mt-switch.is-iconized
 Cross/check sit in the track, opposite the thumb. Icon shows current state but lives separately from the moving piece. 44px wide.
Iconized — thumb
.mt-switch.is-iconized-thumb
 Icon rides inside the thumb circle. Off: grey cross on white. On: brand check on white over brand track. State + thumb are one element — Material 3 / Stripe pattern.
My recommendation: High-contrast. Best visibility without breaking the restrained Mantel aesthetic or our checkbox/radio family..is-strong · .is-labeled · .is-iconized
