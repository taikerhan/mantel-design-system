Horizontal scroll · wide tables
Two mobile options: the stacked list (default — each row becomes a list item, no scroll) and the horizontal-scroll table with a frozen first column for genuinely wide / dense tables. The right-edge fade signals there's more to scroll under the frozen Name.list · .is-responsive

Row actions menu

.mt-row-action → .mt-menuThe ··· opens the standard dropdown · Delete is the danger item
Edit / Duplicate / Activate-Deactivate / Delete (danger). Same .mt-menu used everywhere — open it anchored to the row's ··· button..mt-menu-item.is-danger
Do

Drive columns from a single --mt-cols so the header and every row align. Right-align numeric / currency columns with tabular-nums; left-align text and dates. Keep the ··· always visible at ink-500 so the row reads as actionable.

Don't

Don't use a native <table> — column sync across header and rows is the whole point of the grid. Don't try to ellipsis a flex cell directly; always wrap truncating text in .mt-td-truncate. Don't hide the row action behind hover-only.
