Default vs brand — when to use

emphasis matches the surface
VariantUse it when
default (ink thumb)Low-emphasis state / view toggles that sit alongside other content — a List / Board / Calendar switcher, or a secondary filter. The quiet ink-100 track + ink-900 thumb shouldn't compete with the page's primary action. This is the everyday default.
brand (gradient)When the segmented control is the primary control on the surface — e.g. the main Active / Inactive filter at the top of a settings page. The brand thumb carries the same gradient + elevation as the primary button, so treat it like one: ≤1 brand segmented per surface, and don't pair it next to a primary button competing for the same emphasis.

Do

Use for 2–4 mutually exclusive options. Default ink thumb for low-emphasis toggles; brand for the primary filter on a settings surface.

Don't

Exceed ~4 options (use tabs or a select instead). Don't use it for a primary action choice — that's a button group.
