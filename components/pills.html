When to use which

never borrow a status color for a category
FamilyWhen
lifecycleProposal state — draft / sent / viewed / signed / lost. Carries a dot; colors are the canonical --life-* tokens.
status aliasGeneric semantic state outside the proposal flow — success / warning / info / destructive / muted (system messages, validation, flags).
neutralNon-actionable / stalled reasons — No response, Expired, Archived. Grey, no dot, never a status color.
categoryClassifies WHAT something is (Option / Package) — see Category pills. Light blue / violet; never borrows green / amber / red.

Do

Use lifecycle variants for proposal state and status aliases for everything else. Add a dot to state pills; keep neutral greys dot-free.

Don't

Color a category pill with a status color, or stack a ring on the tint. One pill per cell — they label, they don't act (except the removable ×).
