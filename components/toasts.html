Status is carried by the whole surface — green for success, red for errors, with neutral toasts staying on the dark ink-900 surface. Actions are text-style buttons — white primary, muted secondary trails..mt-toast-actions · .mt-toast-action · .is-bare

When to use

brief, low-stakes, auto-dismiss
ToneColorWhen
success--accent-greenConfirm an action completed — proposal sent, document signed, changes saved. The default for any positive acknowledgement.
danger--accent-redSomething failed or needs attention now — upload failed, lender declined, sync error. Pair with an action when there is a clear recovery path.
neutral--ink-900Informational, no judgement — draft auto-saved, link copied, filter applied. Stays on the dark surface so it does not read as success or error.

Reach for a toast when the message is brief, non-blocking, and safe to miss — it auto-dismisses and never demands a click. Use an Alert instead for persistent, in-context status that must stay on screen, and a Modal for anything that requires a decision before continuing.
