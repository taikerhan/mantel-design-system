Buttons

8px rounded · default + destructive carry elevation · ≤1 primary per surface · 5 variants · 5 sizes

Default

.btn .btn-default36px · the single focal action · variant="default"
Vertical brand gradient (brand-500 → 600) + layered elevation (--shadow-button); hover deepens, active presses inward. Text white · 14px / 500. Front-end size default = 36px.height 36 · radius 8

Secondary & outline

.btn .btn-secondary · .btn .btn-outlineStandard CTA · outline is a kept-for-compat alias
1px solid brand-600 border · text brand-600 (matches the border) · bg white · hover fills brand-50 and deepens to brand-700. .btn-outline is an alias of secondary — prefer secondary in new code.height 36 · radius 8

Destructive

.btn .btn-destructiveIrreversible focal action inside a confirm
Elevated red gradient — the same elevation language as default — reserved for the focal action in a destructive confirm (Deactivate, Delete). Pairs with a flat .btn-neutral Cancel.elevated

Link

.btn .btn-linkInline navigational text — reads as a link, not a button
No background, border, or padding — brand-700 text, underlined by default. Use for inline navigation (e.g. “Learn more”), never as a primary action.text-only

Icon button

.btn .btn-icon36² · brand-bordered standalone control
White fill + 1px brand-600 border at rest — obviously tappable · text brand-700 · hover brand-50 fill + brand-700 border. Note: overlay close buttons and the table .mt-row-action stay neutral gray on purpose.36 × 36 · radius 8

Leading & trailing icons

.btn svgOrder the icon before or after the label — the flex gap spaces it
Icons are 16×16, inherit currentColor, and never shrink (flex-shrink: 0); an 8px gap separates them. Leading icon goes before the label, trailing after — just order them in the DOM..btn svg · gap 8

Split button

.mt-btn-splitA primary action + a caret for its less-common variants
Main action on the left, caret trigger on the right · share a single brand-600 surface · hairline divider in white / 20%. The caret opens a Dropdown menu of the rarer variants..mt-btn-split-main · .mt-btn-split-caret

Sizes

.btn-sm · .btn-compact · .btn-lg · .btn-icon28 · 34 · 36 · 40 · 36²
sm 28px (tight rows) · compact 34px (toolbars beside a 36px search field) · default 36px · lg 40px (marketing / empty-state CTAs) · icon 36². Front-end size prop.28 · 34 · 36 · 40

States

.is-loading · .btn-spinner · :disabledloading + done mirror the front-end props
loading shows a spinner + optional loadingText and blocks pointer events; done swaps in a check for a completed action; disabled drops to 50% opacity.is-loading · is-done

When to use each variant

one primary per surface
VariantWhen
defaultThe single primary action on a surface — Save, Send, Add. Max one per view; it carries the brand gradient + elevation.
secondaryThe standard CTA when there is no single dominant action, or alongside a primary (e.g. “View details”). White with a brand border.
outlineAlias of secondary, kept for existing consumers. Prefer secondary in new code.
destructiveIrreversible / data-losing confirms — Deactivate, Delete. Reserve for the focal action inside a confirm dialog.
linkInline navigational text that reads as a link, not a button (e.g. “Learn more”).

Do

One primary (default) per surface. Pair default + secondary side-by-side; icon buttons trail. Reach for link for low-emphasis inline actions.

Don't

Stack two defaults. Don't elevate secondary / outline — elevation is reserved for the default and destructive focal actions.
